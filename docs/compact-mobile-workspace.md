# 紧凑工作空间与手机性能

本轮按用户新反馈调整，不改变数据模型、权限和订阅消耗规则。

- 页面使用“工作台、订阅账户、配置库、到期日程、访问动态、账户设置”等短标题。移除首页与登录页宣传区、轨道 SVG、英文眉题和重复介绍，保留真实状态、失败反馈及危险操作说明。
- 工作空间不再导入 Motion，也不整页重复挂载做入场动画。快速搜索、账户编辑器和 YAML 编辑器在打开时加载；js-yaml 不随配置列表首屏下载。列表和导航关闭自动 Link 预取，防止手机静默请求全部详情。
- 手机弹层不用全屏 backdrop-filter；去掉悬停位移、循环骨架动画。按钮触摸高度至少 44px，表单 16px 输入字体，保留键盘与焦点行为。
- 每个账户行直接提供 Shadowrocket 复制，原普通订阅复制与详情内复制保留。只读取受保护元数据，复制不消耗访问次数，不缓存 token 到持久存储。
- 支持 ClipboardItem 的浏览器在点击同步阶段开始 clipboard.write，以 Promise 等待元数据，避免 WebKit 在 await 后失去用户激活。文本 API 回退、权限失败及元数据失败各自验证。

## 验证口径

`scripts/measure-workspace-assets.mjs` 对比基线 e68f0a9 与新生产构建：根布局 + 工作空间布局 + 页面在 App build manifest 中声明的初始 JS 去重后字节及 gzip 总和。它是构建包体对比，不是网络实测耗时、帧率或真机 Lighthouse 分数。并检查三个编辑/搜索边界确实有未包含在初始列表中的异步 chunk。

原有 38 项 Chromium 测试保持覆盖，只更新已删除宣传区相关定位和动效断言；新增 5 项紧凑界面/直接复制回归，并使用 WebKit 再跑这 5 项。控制的剪贴板适配器验证调用顺序、内容、错误和不消耗额度，不冒充 iPhone 原生剪贴板或硬件真机验收。5 项单元测试覆盖剪贴板承诺写入及回退。
