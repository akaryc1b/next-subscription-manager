# sub. / Orbit 产品界面

## 产品立场

这个仓库交付的是订阅配置，不是通用云监控。管理员需要判断：谁需要处理、用户获准使用哪些配置、如何交付链接、一次访问为什么成功或被拒绝。界面必须围绕这些任务组织，不增加与数据模型无关的“采集状态”“在线率”或装饰性健康评分。

Orbit 使用明亮纸色、墨绿色文字、荧光青柠主操作和电光蓝信息强调。品牌标志与轨道图形由本地 SVG 绘制，不依赖远程图片、字体或运行时素材服务。轨道表达配置—授权—分发，不表达实时拓扑或节点在线。

## 信息与操作

工作台不是卡片拼接。首屏是一句基于真实数据的处理摘要，随后是账户处理队列、真实七日订阅返回趋势与近期事件。只保留会改变下一步操作的信息。

订阅账户使用可扫描列表与授权抽屉。状态优先级为封禁、停用、到期、无订阅、额度用尽、无可用配置、七日内到期、条件满足。配置名称直达真实配置编辑，不把含凭据的订阅地址伪装成公开服务网址。复制链接不应请求订阅内容接口，因为后者会消耗额度。

配置库默认只读取元数据，进入编辑后才读取 YAML。修改前展示分配账户数；已经分配的配置需要确认发布影响。语法验证只保证 YAML 对象可解析，不声称节点可连接或所有客户端支持。

访问动态先呈现结果与关联对象。详情呈现准确时间、来源、响应、客户端和下一步建议。当前数据没有配置历史快照，因此不可把当前配置名称冒充当时分发内容，也不可拼出虚构的变更前后对比。

到期日程以本地日期聚合可处理账户，避免用大面积空白月历掩盖重要事项。统计窗口明确：安全提示与内容返回为近24小时；趋势为UTC自然日，今日未结束；到期按精确时刻判定。

## 组件与动效

复用已有 Radix Dialog 的焦点约束、键盘关闭和对话框语义，以及 Motion 的页面进入、导航指示与系统减弱动态偏好。Lucide 图标保持一致描边。命令面板用 Cmd/Ctrl+K 打开，支持真实账户/配置搜索与键盘选择。

动效用于定位、反馈和层级转换，不持续占用注意力。prefers-reduced-motion 下取消装饰动画与非必要位移。错误、空数据、加载和成功必须各自表达，不用默认0值隐藏读取失败。

## 工程边界

`/api/workspace` 是管理员只读查询入口，分页最大100、时间范围最大31天、列表不返回token。原有认证、写接口、令牌规则、权限守卫和数据库结构保持不变。Prisma 类型必须由 `pnpm db:generate` 生成，不允许声明一个宽松客户端类型覆盖真实生成类型。

登录、激活和设置保留原有认证能力；此轮重点是工作空间与五条核心管理路径，并未宣称外部客户端或节点连通已验收。

## 验证

`pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 为基础检查。

Workspace browser acceptance 工作流创建仅限localhost/workspace_e2e的临时PostgreSQL数据库，通过真实认证和API驱动生产构建。测试覆盖未授权访问、桌面/手机边界、时间轴详情、键盘搜索、账户创建交付、额度持久化、YAML错误、危险操作取消、读失败恢复、深色与减弱动态。截图与报告上传为 `orbit-browser-evidence`，其中数据是验收fixture，不是生产数据。

验收不能只有截图。所有主操作必须真实可执行；任何未通过或尚未覆盖的环节，应在PR中明确记录。截图可帮助检查排版，不替代真机、触摸、不同浏览器和用户审美评审。
