# Orbit 合并前回归

本轮只收尾 PR #25 的已知问题，不更换视觉方案、不扩展产品模块。

## 修复范围

- 命令面板在防抖期间不展示上一次请求的可操作结果；请求响应绑定 URL 和刷新版本，切换查询的第一次渲染也不会借用旧数据。
- 退出登录先检查未保存编辑，再调用认证接口。桌面与移动导航使用同一入口；撤销修改后恢复退出，失败时不伪装成功。
- 启用且未封禁的普通用户缺少 Subscription 时，同样计入关注列表与首页关注总数。暂停/封禁用户和管理员不因此被误报。
- 认证事件的 identifier 参与不区分大小写的查询，并以“请求标识”显示。尝试邮箱不被推断为已验证的账户所有者。订阅和激活标识沿用日志写入时的掩码；不返回整个 metadata。
- 账户和配置分页在同一 RepeatableRead 只读事务快照中计数并读取。请求页超出最后一页时返回最后一个有效页，pagination.page 反映实际页；集合为空时 page=1、pageCount=0。
- 固定日期的动态刷新既保留时间区间，也更新读取版本，能够获得后到的日志。
- 已有启用配置、尚无订阅用户时，首页主操作进入创建账户，而不是再次提示创建第一份配置。

## 新增验收

`tests/browser/z-merge-regressions.e2e.mjs` 补充 11 项浏览器回归，不删除、不跳过原有验收用例。

搜索用受控时钟和暂缓的真实请求分别覆盖防抖期与请求期的立即回车。无订阅统计、认证搜索、两类分页删除和固定日期刷新使用独立本地 PostgreSQL 的真实 API 与数据；临时记录按精确 ID 清理。

两项新手引导是明确标注的 UI 响应夹具；两项退出保护在放行后的失败处理阶段注入 503，避免撤销其他用例共享的真实认证会话。它们不被当作外部认证或真实退出成功的证明。

新用例只允许 WORKSPACE_E2E=1 且数据库地址为 localhost/127.0.0.1 的 workspace_e2e，拒绝接触部署数据库。实际通过结果应以最终提交关联的 CI 和浏览器报告为准。
